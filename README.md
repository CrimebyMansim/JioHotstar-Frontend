# JioHotstar Frontend

A JioHotstar-inspired streaming website front page built using HTML and CSS.

## 🚀 Features
- Modern dark theme UI
- Movie and web series banners
- Trending movies section
- Popular channels
- Responsive layout

## 🛠️ Technologies Used
- HTML
- CSS

## 📂 Project Structure
- `css_work` – CSS files
- `html_work` – HTML files
- `images` – Website images
- `video` – Website videos
